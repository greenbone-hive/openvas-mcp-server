# Releases

Every release ships binaries for five platforms, the container image
`ghcr.io/greenbone-hive/openvas-mcp:v<version>`, a software bill of materials
and signed build provenance for every artifact. Download them from the
[GitHub releases page](https://github.com/greenbone-hive/OpenVAS-MCP/releases);
the release process itself is described in
[RELEASING.md](https://github.com/greenbone-hive/OpenVAS-MCP/blob/main/RELEASING.md).
